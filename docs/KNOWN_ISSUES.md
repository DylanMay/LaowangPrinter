# 已知问题

MVP 1.0 冻结后只修阻塞缺陷，不擅自加功能。下一阶段见产品文档第 15 节与开发计划第 12 节。

## 阻塞现场验收的事项

- **实机未在本仓库的云端环境验收。** 无 USB 激光机。Mock 已走通主路径；实机需按空载 → 低功率 → 标准的顺序现场做。
- **安装包需在对应系统本机打。** 仓库已提供 `npm run dist:win` / `npm run dist:mac`，但无 CI、无代码签名。未签名的 Windows 包会过 SmartScreen，macOS 包会过 Gatekeeper。

## 非阻塞

- 工作区右侧属性栏在窄宽度下仍可能出现横向滚动条。
- 首次引导遮罩下，首页标题仍可见；选择文件区在引导期间已隐藏。
- 仓库里的 `docs/ui` HTML 原型不是桌面应用，开发时可能和 Electron 窗口同时出现在桌面上。
- Linux 上列举真实串口曾出现 `udevadm` 卡住；已对列举加超时。个别发行版仍可能慢。
- 模拟运动为了能看见进度，默认延迟 700ms，比真机 idle 应答慢。
- 低功率测试用「轻度」效果参数，不是独立功率校准表。
- 应用未签名；macOS Gatekeeper / Windows SmartScreen 可能拦截未打包的开发运行。

## 明确不做（下一阶段）

PNG / JPG、灰度雕刻、更多材料校准、DXF、相机定位、AI、云账号。
