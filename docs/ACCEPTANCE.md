全程普通路径不出现 COM3、115200、G-code、M3、S/F、GRBL。这些只在高级设置。

## 实机安全顺序（现场）

1. 只连接、只读配置，确认点动 / 回原点不开激光。
2. 空载测试看路径。
3. 用户明确确认后的低功率测试。
4. 木板标准参数正式雕刻。
