# 老王打印机 UI 设计

版本：MVP 1.0  
原型：[ui/index.html](./ui/index.html)（可点击，浏览器打开）  
配套：[产品文档](./PRODUCT.md)

本文冻结第一版视觉与页面。实现时按此出码，不要做成 CNC 控制台。

---

## 1. 设计原则

1. **像打印机，不像机床。** 用户心理是「把这张图印到木板上」，不是「控制 GRBL」。
2. **一屏一件事。** 首页只做连接与导入；工作区只做尺寸、材料、预览；任务页只做确认、进度、结果。
3. **主按钮不超过五个：** 选择文件、预览、开始雕刻、暂停、停止。其余全部弱化。
4. **技术词进高级设置。** 主界面不出现 COM、波特率、G-code、M3、S、F、Alarm、Homing。
5. **安全是流程，不是小字。** 开始前必须确认；空载测试默认建议；停止必须二次确认。
6. **能用状态条就不用弹窗。** 仅开始雕刻、停止、重置、删除需要 Modal。

---

## 2. 视觉语言

参考：家用打印机软件、Cricut 一类的桌面工艺工具。不要暗色工业风、不要绿字终端、不要密密麻麻的坐标读数。

### 2.1 色彩

| Token | 色值 | 用途 |
| --- | --- | --- |
| `--paper` | `#F3EEE6` | 窗口背景，纸感 |
| `--surface` | `#FFFCF7` | 卡片、工作台 |
| `--ink` | `#1C1814` | 主文字、主按钮 |
| `--muted` | `#6B645C` | 次要说明 |
| `--line` | `#E4DCD0` | 分割线 |
| `--brand` | `#215C4C` | 已连接、主强调、空载建议 |
| `--ok` | `#2C9B6A` | 成功、完成 |
| `--warn` | `#C4842A` | 越界、需要处理 |
| `--danger` | `#C4473A` | 停止、断开、异常 |
| `--laser` | `#D85A38` | 预览路径，不是主按钮色 |

开始雕刻用 **墨色实心按钮**，不要用红色。红色留给停止和危险。

### 2.2 字体

中文优先：`Noto Sans SC`、苹方、冬青黑体。  
字号：页面标题 28–32px；区块标题 15px 中粗；正文 14px；辅助 12–13px。  
不要等宽字体出现在普通用户界面（高级设置除外）。

### 2.3 圆角与间距

- 大卡片 20px，控件 12px，胶囊 999px
- 间距走 8 的倍数：8 / 16 / 24 / 32 / 48
- 阴影极轻：`0 12px 40px rgba(28,24,20,.08)`，不要厚重拟物

### 2.4 窗口

桌面窗口约 **1280 × 800**。自绘顶栏：品牌、设备状态、帮助、设置。不把菜单做成 CAD 工具条。

## 3. 三个核心页面

不要拆成十几个路由。所有复杂状态都是这三个页面上的变化。

```
Home          连接 + 导入
Workspace     摆图 + 材料 + 预览
Job           确认 + 进度 + 完成/失败
```

---

## 4. 页面清单

### 4.1 首页 Home

**未连接**

- 大标题：激光雕刻
- 拖入区禁用或降噪，说明「请先连接雕刻机」
- 状态：○ 未检测到雕刻机
- 按钮：[连接设备] [连接帮助]

**查找中**

- 状态脉冲：正在查找雕刻机…
- 不展示 COM 列表

**已连接**

- 拖入区成为唯一主操作：「拖入图片开始雕刻」+ [选择文件]
- 状态：● 雕刻机已连接（名称固定为「我的雕刻机」）

**第一次连上**

- 不弹十几条说明
- 一条提示：「我们先确认雕刻机工作正常。」[开始测试]

### 4.2 工作区 Workspace

```
顶栏：老王打印机    ● 已连接     帮助  设置
左：工作台 300×200 mm，图案居中，无 X0Y0Z0
右：尺寸 / 材料 / 效果 / 工作方式
底：范围、预计时间、[预览] [开始雕刻]
```

右侧默认值：木板、3mm、标准、空载测试（建议）。  
效果三档用分段控件，不要滑块功率。  
底部必须有一句：实际效果会因机器、激光功率和材料不同而有所差异。

**越界：** 工作台外侧红色斜纹，顶栏警告「图案超出雕刻区域」，开始按钮禁用。  
**过大：** 警告「图案太大。当前工作区域为 300 × 200 mm。」[自动缩小]

### 4.3 雕刻预览

不是 G-code 文本。全屏或工作区内覆盖：

- 工作台 + 路径
- 小圆点沿路径移动
- 预计 1 分 32 秒 · 50 × 30 mm · 3mm 木板 · 标准
- [返回修改] [开始雕刻]

### 4.4 开始前检查（Job）

Modal，必须用户点「开始雕刻」才开激光：

- 检查项全部打勾才允许主按钮
- 三句确认：已放材料、工作区安全、材料适合本机
- 空载测试时主按钮文案改为「开始空载测试」，并写明「机器会移动，但不会开激光」

### 4.5 进行中

工作台仍可见，底部变为任务条：

- 正在雕刻… / 空载测试中…
- 进度条 + 68% + 预计剩余 42 秒
- [暂停] [停止]
- 不要把「第 125 / 523 行」放在主位置

暂停：文案「雕刻已暂停」[继续] [停止]  
停止：确认「停止后需要重新开始任务。」[继续雕刻] [停止]

### 4.6 完成 / 失败

完成：大勾、雕刻完成、用时、[再次雕刻] [返回首页]  
USB 拔出：雕刻机连接已断开。请检查 USB 连接。[重新连接]  
设备异常：雕刻机处于异常状态。请检查机器，然后重新归零。[查看帮助]  
串口占用：无法连接雕刻机。可能有其他软件正在使用这台设备。[重试]

### 4.7 首次引导（一步一任务）

1. 连接雕刻机  
2. 确认设备  
3. 测试机器移动  
4. 放置材料  
5. 开始第一次雕刻  

每步只有一个主按钮。测试移动必须是低风险点动，界面写「正在轻轻移动机器…」，完成后「设备移动正常」。

### 4.8 高级（弱化）

从设置进入，默认不出现在主路径：

- 我的雕刻机 · COM3 · 115200 · GRBL 1.1h · 300×200 mm · 最大功率 1000 · 激光模式
- 查看 G-code、串口日志
- 机器控制：点动 1/10/100 mm，速度四档，「回到原点」过程文案为「正在寻找机器原点…」
- 重置：独立危险操作，需确认，文案「正在重置雕刻机」

## 5. 组件

| 组件 | 用法 |
| --- | --- |
| 主按钮 | 墨色实心，每屏最多一个 |
| 次按钮 | 白底线框 |
| 危险按钮 | 红字线框；确认停止才用红底 |
| 状态胶囊 | 点 + 短句，放顶栏右侧偏左 |
| 拖入区 | 虚线大卡片，是首页唯一视觉中心 |
| 工作台 | 浅木色矩形，比例跟随机器尺寸 |
| 分段控件 | 效果、工作方式 |
| 横幅 | 越界 / 断开 / 成功，贴在工作区上方，不是 Modal |
| Toast | 居中、自动缩小、已居中 等轻反馈 |
| Modal | 仅安全确认、停止、重置、删除 |

## 6. 文案对照（界面必须遵守）

| 禁止 | 使用 |
| --- | --- |
| Connect GRBL | 连接雕刻机 |
| G-code Sender | 雕刻任务 |
| Feed Rate | 雕刻速度（仅高级） |
| Spindle Power | 激光功率（仅高级） |
| Homing | 回到原点 |
| Alarm | 设备异常 |
| COM3 / 115200 | 我的雕刻机 |
| Line 125/523 | 68% · 预计剩余 42 秒 |

空状态：

- 把图案拖到这里
- 请连接雕刻机
- 请选择材料
- 还没有雕刻任务

---

## 7. 与实现的关系

原型是视觉与交互的真源。Electron 实现应对齐：

- 三个页面结构
- 默认空载测试
- 开始前检查清单
- 越界立即反馈
- 高级设置收纳全部协议细节

不要在实现阶段把 Jog 速度、串口列表、G-code 行号加回主界面。
