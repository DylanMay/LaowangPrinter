# 老王打印机（LaowangPrinter）产品文档

版本：MVP 1.0  
文档类型：产品需求与体验规范  
状态：待开发

---

## 1. 产品一句话

老王打印机是一台激光雕刻机的「打印软件」：用户选图案、选材料、调尺寸、点开始，就能完成第一次雕刻。

它不是 GRBL 控制器，也不是专业 CNC 软件。

> 让软件理解机器，让用户只需要理解自己想刻什么。

---

## 2. 产品定位

### 2.1 是什么

面向第一次接触激光雕刻机的普通用户，在桌面端完成：

**图片 → 材料 → 尺寸 → 预览 → 开始**

软件内部负责：

**SVG → Path → 坐标转换 → G-code → GRBL → 串口 → 激光机**

### 2.2 不是什么

不是给专业 CNC 工程师用的控制器。  
不是 CAD。  
不是云平台。  
不是社区或商城。

### 2.3 核心原则

**技术复杂度留给软件，操作复杂度不要留给用户。**

用户不应该被迫理解：

| 底层技术 | 用户应该看到 |
| --- | --- |
| COM3 / `/dev/ttyUSB0` | 我的雕刻机 |
| 115200 | （无需关心） |
| GRBL / G-code / M3 / M5 | （无需关心） |
| S200 / F1000 | 轻度 / 标准 / 深度 |
| MPos / Feed Rate / Spindle | 雕刻进度 |
| RX buffer | （无需关心） |

普通用户只需要理解五件事：

1. 我的雕刻机
2. 我的图片
3. 我要刻多大
4. 我要刻什么材料
5. 开始雕刻

### 2.4 成功标准

一个完全不懂 GRBL、G-code、串口、CNC 的人，不读开发文档，也能在约 **5 分钟**内完成第一次雕刻。

如果用户必须理解 COM3、115200、G-code、M3、S 值、F 值才能完成第一次雕刻，则认为 UX 设计失败。

优先级：

**可靠性 > 易用性 > 功能数量 > 高级性能**

第一版追求「第一次成功」，不追求功能最多。

---

## 3. 目标用户

### 3.1 主用户

第一次接触激光雕刻机的人：

- 不懂 GRBL
- 不懂 G-code
- 不懂串口
- 不懂 CNC
- 不知道激光功率和速度是什么意思
- 不知道机器坐标系
- 不知道 COM3 是什么

心理模型类似「用电脑连打印机」：插上 USB，选一张图，选纸张，点打印。

### 3.2 次用户（高级设置）

愿意进入「高级设置」查看串口、G-code、机器尺寸的用户。  
这些信息默认隐藏，不进入主流程。

---

## 4. MVP 目标

第一版只完成一件事：

> 用户可以把一个 SVG 图案雕刻到材料上。

完整链路：

```
SVG
 → SVG Parser
 → Path
 → Coordinate Transformer
 → G-code Generator
 → GRBL Sender
 → SerialPort
 → GRBL
 → 激光雕刻机
```

## 5. 功能范围

### 5.1 P0 必须实现

#### 设备

- USB 串口自动发现
- 自动检测 GRBL
- 自动连接
- 断开
- USB 拔出检测
- 重连
- GRBL 状态检测
- 自动读取机器配置

#### 图形

- SVG 导入
- SVG 预览
- SVG 自动居中
- SVG 缩放
- SVG 移动
- SVG 尺寸设置（宽 / 高，默认锁定比例）

#### SVG 支持

图形：`line`、`polyline`、`polygon`、`rect`、`circle`、`ellipse`、`path`

Path 命令至少：`M`、`L`、`H`、`V`、`C`、`Z`

Bezier 曲线转换成线段。

#### 材料

第一版必须：

- 木板

可预留（UI 可出现，参数可占位，不要求精细校准）：

- 竹子
- 纸板
- 皮革
- 亚克力

#### 参数（用户侧）

用户看到「雕刻效果」，而不是 Speed / Power：

- 轻度
- 标准
- 深度

内部转换为速度与功率。

#### G-code

支持：`G21`、`G90`、`G0`、`G1`、`M3`、`M5`、`S`、`F`

#### 机器控制（非主流程）

- Jog
- Home（回到原点）
- Pause / Resume / Stop / Reset

这些功能不出现在普通用户的主要操作路径。

#### 雕刻任务

- Start / Pause / Resume / Stop
- Progress / Completed / Error

#### 安全

- 开始前 SafetyChecker
- 开始前确认对话框
- 空载测试模式（默认建议）
- 低功率测试需明确确认
- 默认禁止自动开激光

### 5.2 明确不做（第一版禁止实现）

- DXF / AI / PDF
- 复杂 CAD
- 图片灰度雕刻 / Bitmap engraving
- 相机 / Camera positioning
- 自动对焦
- 材料识别
- AI 图像生成 / AI 抠图
- Nesting
- 复杂刀路优化
- 多机器云管理
- 登录 / 用户系统 / 云同步
- 在线商城 / 社区 / 账号体系

不要为了「未来可能用到」提前开发。

## 6. 用户流程

### 6.1 主流程（必须在 5 分钟内可走完）

```
打开软件
  → 插入激光雕刻机 USB
  → 软件自动发现设备
  → 显示「已连接雕刻机」
  → 拖入图片 / SVG
  → 软件自动显示在工作区域
  → 自动居中
  → 用户调整大小
  → 选择材料
  → 软件自动推荐参数
  → 预览
  → 开始雕刻
  → 安全检查
  → 用户确认
  → 雕刻
  → 完成
```

页面不超过三个核心页面：

1. **Home** — 连接设备、导入图案
2. **Workspace** — 调整尺寸、选择材料、预览
3. **Job** — 安全确认、进度、完成 / 错误

### 6.2 首次使用引导

第一次启动不要一次给十几条说明。一步一个任务：

1. 连接雕刻机
2. 确认设备
3. 测试机器移动
4. 放置材料
5. 开始第一次雕刻

第一次检测到设备时提示：

> 我们先确认雕刻机工作正常。  
> [开始测试]

执行低风险的机器移动测试。完成后：

> 设备移动正常 ✓  
> 现在可以进行第一次雕刻。

### 6.3 第一次雕刻默认值

| 项 | 默认 |
| --- | --- |
| 材料 | 3mm 木板 |
| 效果 | 标准 |
| 尺寸 | 根据 SVG 自动计算 |
| 位置 | 居中 |
| 工作模式 | 建议空载测试 |

不要让用户第一次面对十几个参数。

## 8. 交互细则

### 8.1 设备发现与连接

用户插入 USB 后：

1. 自动扫描串口
2. 自动尝试检测 GRBL
3. 成功则显示「✓ 雕刻机已连接」
4. 失败则显示「没有检测到雕刻机」，提供 [重新检测] [连接帮助]

连接成功后自动读取配置（用户不可见）：`$$`、`$G`、`$30`、`$31`、`$32`、GRBL version、机器尺寸、Laser Mode、最大功率。

如果无法自动获得机器尺寸，才进入设置引导。不要一连接就让用户输入大量参数。

### 8.2 SVG 导入

用户可拖拽 SVG，或点击「选择文件」。

导入后自动：解析 → 转换单位 → 计算尺寸 → 自动缩放（必要时）→ 自动居中 → 显示在工作区域。

用户可：

- 拖动
- 缩放
- 修改宽度 / 高度
- 锁定比例（默认开启）
- [居中]
- [适应工作区]

属性示例：宽 50 mm，高 30 mm，位置：居中。

### 8.3 超出工作区域

图案移出工作区域时 **立即** 提示，不要等到发送 G-code：

> 图案超出雕刻区域

视觉上标出超出部分。禁止点击「开始雕刻」，或点击后走最终检查并拦截。

图案大于机器时：

> 图案太大  
> 当前工作区域为 300 × 200 mm。  
> [自动缩小]

自动缩小保持比例。例如 320 × 100 → 300 × 93.75，然后：

> 已调整到工作区域内。

### 8.4 材料与效果

普通用户不要直接设置 Power / Speed。

- 材料：[木板 ▼]
- 厚度：[3 mm ▼]
- 效果：○ 轻度 ● 标准 ○ 深度

UI 必须明确：

> 实际效果会因机器、激光功率和材料不同而有所差异。

不要把参数描述成绝对正确。

### 8.5 预览

默认页面是「雕刻预览」，不是 G-code：

- 图案
- 机器工作区域
- 雕刻路径
- 预计时间：1 分 32 秒
- 雕刻范围：50 × 30 mm
- 材料：3mm 木板
- 效果：标准

预览模式模拟激光头移动（小圆沿路径走），让用户在真正雕刻前知道机器将如何运动。

「查看 G-code」只出现在高级设置。

### 8.6 工作模式

- ○ 正常雕刻
- ● 空载测试（第一次建议此项）

空载测试：XY 正常移动，禁止真正开启激光。所有 `M3 Sxxx` 必须被安全处理（例如转为 `M5`）。

「低功率测试」仍然可能产生激光输出，默认不要自动执行，需要用户明确确认。

### 8.7 机器控制（高级 / 弱化入口）

Jog 不出现在普通用户主流程。放在「机器控制」或「高级」。

- 步进：1 mm / 10 mm / 100 mm
- 速度：100 / 500 / 1000 / 3000

Home 对用户显示「回到原点」，过程中显示「正在寻找机器原点...」，不要直接显示 Homing。

暂停：UI「雕刻已暂停」，提供 [继续] [停止]。

停止：先确认。

> 确定停止当前雕刻吗？  
> 停止后需要重新开始任务。  
> [继续雕刻] [停止]

不要自动偷偷 Reset。Reset 是高级功能，显示「正在重置雕刻机」。

### 8.8 弹窗原则

尽可能使用 Toast、Inline message、Status，而不是大量 Modal。

只有以下操作需要确认：

- 开始雕刻
- 停止任务
- Reset
- 删除内容

### 8.9 核心按钮

主流程只突出：

- 选择文件
- 预览
- 开始雕刻
- 暂停
- 停止

其他功能弱化。

## 9. 文案原则

使用自然中文。普通用户界面禁止工程术语。

| 不要写 | 要写 |
| --- | --- |
| Connect GRBL | 连接雕刻机 |
| G-code Sender | 雕刻任务 |
| Feed Rate | 雕刻速度 |
| Spindle Power | 激光功率 |
| Homing | 回到原点 |
| Alarm | 设备异常 |
| COM3 / 115200 | 我的雕刻机（高级设置里可显示） |

高级设置可以显示技术名称。

### 9.1 空状态

| 场景 | 文案 |
| --- | --- |
| 没有文件 | 把图案拖到这里 |
| 没有设备 | 请连接雕刻机 |
| 没有选择材料 | 请选择材料 |
| 没有任务 | 还没有雕刻任务 |

### 9.2 错误必须翻译成用户能懂的中文

绝对不要让普通用户看到：`TypeError`、`SerialPortError`、`ENOENT`、`error:20`、`Access denied`。

| 技术原因 | 用户文案 |
| --- | --- |
| USB 被拔出 | 雕刻机连接已断开。请检查 USB 连接。[重新连接] |
| 串口被占用 | 无法连接雕刻机。可能有其他软件正在使用这台设备。[重试] |
| GRBL Alarm | 雕刻机处于异常状态。请检查机器，然后重新归零。[查看帮助] |
| GRBL `error:20` | 雕刻机无法执行当前动作。可能是图案或机器设置存在问题。高级设置显示 `GRBL error:20` |
| 图案超出 | 图案超出雕刻区域 |
| 图案太大 | 图案太大。当前工作区域为 300 × 200 mm。[自动缩小] |

雕刻过程中 USB 被拔掉：立即停止发送，任务进入错误，设备进入未连接，通知用户。不要继续发送数据。

## 11. 安全原则

这是激光设备控制软件。默认 **安全优先**。

1. 不要自动打开激光。
2. 不要自动开始任务。
3. 不要在后台偷偷执行运动。
4. 不要因为连接设备而自动执行危险动作。
5. 只有真正开始雕刻任务时才允许开启激光。

以下操作 **绝对不能** 自动开启激光：

- 打开软件
- 连接机器
- 导入 SVG
- 移动图案
- 生成 G-code
- 预览
- Home
- Jog
- 打开高级设置

点击「开始雕刻」之后不能立即发送激光，必须经过 SafetyChecker 与用户确认。

SafetyChecker 检查：

1. 设备已连接
2. GRBL 状态正常
3. 图案存在
4. 图案没有超出工作区域
5. G-code 存在
6. 材料已选择
7. 参数有效
8. 当前不是 Alarm 状态
9. 机器处于可执行状态

## 12. UI 设计规范

### 12.1 风格

现代、简洁、专业，但不要像工程软件。

参考感觉：**打印机软件**，而不是 CNC 控制器。

用户应该觉得：「我要把这个图案刻出来。」  
而不是：「我要控制 GRBL。」

### 12.2 布局

- 顶部：品牌、设备状态、帮助、设置
- 中央：工作区
- 右侧：图案 / 材料 / 效果
- 底部：任务摘要与主操作

工作区画布以机器物理尺寸为基准（如 300 × 200 mm），图案居中显示。不要默认显示坐标系原点数值。

---

## 13. 状态（产品视角）

用户可感知的状态必须互斥、清晰，不要用互相冲突的开关。

### 设备

未连接 → 正在检测 → 正在连接 → 已连接 / 出错

### 机器

未知 → 空闲 → 运行中 → 已暂停 → 设备异常 → 正在回到原点 → 已断开

### 任务

未开始 → 准备中 → 就绪 → 雕刻中 → 已暂停 → 已停止 → 出错 → 已完成

对应界面：

- 已连接 / 未检测到雕刻机
- 正在雕刻 / 雕刻已暂停 / 雕刻完成
- 雕刻机连接已断开 / 雕刻机处于异常状态
